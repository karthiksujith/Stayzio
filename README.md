# Stayzio

Stayzio is a full-stack hotel booking web application built with Laravel, PHP, MySQL, Blade, and Vite.

It allows users to search for properties, view property details, make bookings, manage their reservations, and cancel bookings. Hosts can create and manage their properties and manage guest bookings.

## Features

### User Features

* User registration and login
* Search properties by location
* Search by dates and number of guests
* View property details and images
* Book available properties
* View booking history
* Cancel bookings
* Profile management
* Demo payment system

### Host Features

* Host registration and login
* Create properties
* Update property details
* Delete properties
* Upload property images
* View property bookings
* Confirm and manage bookings

### AI Chatbot

Stayzio includes an AI-powered chatbot that can help users:

* Understand how Stayzio works
* Find properties based on their requirements
* Get help with bookings
* Understand cancellation and payment information

## Requirements

Before running the project, make sure you have:

* PHP 8.2 or higher
* Composer
* MySQL
* Node.js and npm
* XAMPP or another PHP development environment
